# 从沙子到芯片 · Sand to Chip 🏖️→💻

一个交互式 **3D** 可视化网页,完整展示 **硅的提取提纯** 与 **光刻机芯片制造** 全流程 —— 两章 15 步,每一步都是一个可旋转、可缩放的 3D 场景(设备剖视 + 微观结构),配有工艺动画、3D 标注、详细讲解与关键数据。

## 运行

直接双击 `index.html` 即可(已打包成单个脚本,`file://` 也能运行);或使用任意静态服务器:

```bash
python -m http.server 8217
# 打开 http://localhost:8217
```

## 内容

### 第一章 · 硅的提取与提纯
| # | 场景 | 建模要点 |
|---|---|---|
| 1 | 石英 | 六方柱 + 菱面体端面的水晶晶簇(透射/折射材质)、石英砂粒;α-石英原子结构按真实晶体学坐标(P3₂21)生成 |
| 2 | 矿热电弧炉 | 1/4 剖视:三相石墨电极、电弧空腔、液态硅熔池、碳砖炉衬、铜接触瓦、出硅口与硅包、火焰与微硅粉烟气 |
| 3 | 西门子法 | 钟罩还原炉剖视,18 对 U 形硅棒通电发光并实时变粗;精馏塔、多晶硅棒截面 |
| 4 | 直拉单晶 | 单晶炉热场剖视(加热器、石英坩埚、热屏、保温毡),晶棒经引晶→缩颈→放肩→等径实时生长,成品晶棒带 4 条 <100> 棱线 |
| 5 | 多线切割 | 导轮 + 150 根钢线线网,晶棒下压后线网以下分离成一片片晶圆;成品晶圆花篮 |
| 6 | CMP 抛光 | 抛光台 / 抛光头 / 抛光液臂 / 金刚石修整器;AFM 伪彩色表面形貌从微米级被磨平到亚纳米级 |
| 7 | 成品晶圆 | 镜面晶圆(立方体相机实时反射洁净室)、缺口与激光刻号、FOUP 晶圆盒、天车 OHT |

### 第二章 · 光刻与芯片制造
| # | 场景 | 建模要点 |
|---|---|---|
| 1 | 热氧化 | 立式氧化炉剖视,晶舟升降;晶圆颜色由**物理薄膜干涉**计算,随 SiO₂ 厚度变化;氧化层剖面与干涉色对照卡 |
| 2 | 旋涂光刻胶 | 黄光区、涂胶杯剖视、滴胶臂、胶液铺展与甩胶、软烘热板 |
| 3 | **EUV 光刻机** | 锡滴 + CO₂ 激光 → 等离子体 → 收集镜 → 场/光瞳复眼 → 反射式掩膜 → 6 镜投影物镜 → 晶圆;镜面法线按反射定律计算;掩膜台与晶圆台 4:1 反向同步扫描,曝光场逐个累积 |
| 4 | 显影 | 狭缝扫描喷嘴、冲洗甩干;微观:曝光区溶解,留下带**驻波纹**侧壁的胶线 |
| 5 | 等离子刻蚀 | ICP 腔体剖视(射频线圈、陶瓷窗、等离子辉光、静电吸盘);微观:离子方向性刻出垂直沟槽 |
| 6 | 离子注入 | 离子源 → 90° 质量分析磁铁(杂离子撞壁滤除)→ 加速管 → 扫描 → 终端台;微观:硅金刚石晶格中的硼注入、晶格损伤与退火 |
| 7 | 晶体管与互连 | FinFET(鳍、金属栅、侧墙、SiGe/Si:P 源漏、钨接触)+ 7 层铜互连、通孔、低 k 介质、铝焊盘,按工艺顺序逐层生长 |
| 8 | 测试·切割·封装 | 探针卡测试与晶圆图、划片机切割蓝膜晶圆、引线键合逐根打线、塑封剖视与成品料盘 |

## 操作

- 左键拖拽旋转 · 右键平移 · 滚轮缩放
- 右上角按钮(或数字键 `1`~`5`)切换每个场景的预设视角
- `←` `→` 切换步骤;**▶ 自动播放** 会依次浏览每步的所有视角
- 右下角:标注开关 / 自动环绕 / 全屏
- 地址栏 `#b3` 直达某一步,`#b3.2` 直达某一步的某个视角;`?shot` 只显示 3D 视口

## 开发

```bash
npm install
npm run build   # 打包 src/ → dist/app.js
npm run watch   # 监听修改自动打包
```

| 路径 | 内容 |
|---|---|
| `index.html` | 页面骨架与样式 |
| `src/main.js` | 导航、信息面板、视角切换 |
| `src/data.js` | 15 步的讲解文案与数据 |
| `src/engine.js` | 渲染器、HDR 辉光后期、轨道控制、3D 标注、镜头飞行 |
| `src/lib/` | 材质库(PBR)、程序化纹理、噪声、建模工具箱、粒子系统、洁净室 / FOUP / 晶圆等通用部件 |
| `src/scenes/` | 15 个场景,每个导出 `{ views, build(ctx) → { update(t, dt) } }` |

技术栈:Three.js(PBR 材质、物理薄膜干涉、透射、UnrealBloom 后期、CSS2D 标注)+ esbuild。所有模型与纹理均为代码程序化生成,无外部资源。
