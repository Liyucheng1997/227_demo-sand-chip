# 从沙子到芯片 · Sand to Chip 🏖️→💻

一个纯前端的交互式可视化网页,完整展示 **硅的提取提纯** 与 **光刻机芯片制造** 全流程 —— 两章 15 步,每一步都配有动画 SVG 场景、详细讲解、关键数据与化学方程式。

## 在线预览 / 本地运行

无任何依赖,直接用浏览器打开 `index.html` 即可;或用任意静态服务器:

```bash
python -m http.server 8217
# 打开 http://localhost:8217
```

## 内容结构

### 第一章 · 硅的提取与提纯
1. **原料:石英砂** — SiO₂ 四面体晶体结构
2. **电弧炉冶炼** — 2000°C 碳热还原 → 冶金级硅 (98%)
3. **西门子法提纯** — SiHCl₃ 精馏 + CVD 还原 → 电子级 99.9999999%
4. **直拉法 (CZ) 拉单晶** — 籽晶旋转提拉,300mm 单晶硅棒
5. **金刚石线锯切片** — 一次切出上千片晶圆
6. **化学机械抛光 (CMP)** — 表面起伏 < 1nm 的镜面
7. **成品晶圆** — 进入晶圆厂前的最后形态

### 第二章 · 光刻与芯片制造
1. **热氧化** — 1000°C 生长 SiO₂ 绝缘层
2. **旋涂光刻胶** — 3000~6000 rpm 甩出 1μm 均匀感光膜
3. **光刻机曝光 ★** — 光源 → 照明系统 → 掩膜版 → 4:1 投影物镜 → 晶圆台逐格步进
4. **显影** — 曝光区溶解,图形显现
5. **等离子蚀刻 (RIE)** — 把图案永久刻入材料
6. **离子注入** — 定域掺杂,造出 PN 结
7. **沉积与多层互连** — 30~100 道光刻层的"摩天大楼"
8. **测试·切割·封装** — 芯片诞生 🎉
